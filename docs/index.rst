solveclosure documentation
==========================

``solveclosure`` solves the closure problem for the dual-continuum model
published by Paten et al. It takes a TIF image of an electrode
microstructure, builds an OpenFOAM case and solves the closure problem PDE
on it.

See the following articles for more information:

* https://doi.org/10.1149/1945-7111/ae335f
* https://doi.org/10.1149/1945-7111/ae3527
